# re:Invent 2026 출장 일정 웹앱

홈 화면에 설치해서 쓰는 출장 일정·장소 앱입니다. 데이터는 Firebase(Firestore)에 있고, 고치면 모두의 폰에 바로 반영됩니다.

## 설치

- **아이폰:** Safari에서 앱 주소 열기 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드:** Chrome에서 앱 주소 열기 → ⋮ → **홈 화면에 추가** 또는 **앱 설치**

처음 열 때 보기 비밀번호를 한 번 넣으면 그 기기에 기억됩니다.

## 동작 방식

- **보기:** 보기 비밀번호로 공용 계정(`viewer@example.com`)에 로그인합니다. Firestore 규칙이 이 계정만 읽고 쓸 수 있게 막습니다.
- **오프라인:** 받은 데이터는 기기에 저장되어 인터넷이 없어도 보입니다. 오프라인에서 고친 내용은 연결되면 자동으로 올라갑니다.
- **편집:** 위쪽 **편집** → 편집 비밀번호를 넣으면 추가·수정·삭제할 수 있습니다. 편집 비밀번호는 실수 방지용이며 처음 편집할 때 앱에서 정합니다.
- **바꾼 칸만 저장:** 수정 창을 연 뒤 실제로 바꾼 칸만 올립니다. 같은 항목이라도 다른 칸을 고친 사람의 수정은 지워지지 않습니다.
- **오프라인 수정:** 기존 항목을 오프라인에서 고치거나 지우면 기기의 대기 목록(`localStorage` `rv.outbox`)에 보관합니다. 다시 연결되면 서버 최신 내용과 칸 단위로 비교해, 겹치지 않으면 올리고 같은 칸을 다른 사람이 고쳤거나 항목이 삭제됐으면 사용자에게 물어봅니다. 새 항목은 Firebase가 바로 보관했다가 올립니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html`, `app.js`, `styles.css` | 앱 화면과 동작 |
| `firebase-config.js` | Firebase 웹 앱 설정값(공개 식별값)과 보기 계정 |
| `vendor/firebase.js` | Firebase SDK 묶음(오프라인에서도 앱이 열리도록 함께 배포) |
| `sw.js`, `manifest.webmanifest`, `icons/` | 홈 화면 설치·오프라인용 |
| `firestore.rules` | Firestore 보안 규칙(콘솔에 붙여넣은 것과 같은 내용) |
| `tools/migrate.py` | 처음 한 번 기존 데이터를 Firestore로 옮긴 도구 |

화면 파일을 고치면 `sw.js`의 `CACHE` 이름을 올려야 설치된 앱에 반영됩니다.
`vendor/firebase.js`는 `firebase` npm 패키지(12.x)를 esbuild로 묶은 파일입니다.

## 원본 아티팩트에서 바뀐 내용 반영하기 (관리자용)

2026-11-05에 claude.ai 아티팩트의 데이터를 옮겨 왔습니다. 이후 아티팩트에서 고친 내용은 자동으로 들어오지 않으므로, 필요하면 Claude에게 반영을 요청합니다(원본 아티팩트 링크와 보기 비밀번호를 함께 알려주세요).

기준 시각 **T0 = `2026-11-05T00:08:09.865771Z`** (옮겨 올 때 아티팩트의 가장 최근 수정 시각). 아티팩트와 Firestore 문서의 `updatedAt`을 T0와 비교합니다.

| 아티팩트 | Firestore(웹앱) | 처리 |
|---|---|---|
| T0 이후 수정 | T0 이전 그대로 | 바뀐 칸만 반영 |
| T0 이후 수정 | T0 이후 웹앱에서도 수정 | **둘 다 고쳐짐** → 어느 쪽을 남길지 사용자에게 확인 |
| 새 문서(T0 이후) | 없음 | 추가 |
| 있음(T0 이전) | 없음 | 웹앱에서 삭제한 것 → 그대로 둠 |
| 없음 | 있음(T0 이전) | 아티팩트에서 삭제한 것 → 사용자 확인 후 삭제 |
| 없음 | 있음(T0 이후) | 웹앱에서 만든·고친 것 → 그대로 둠 |

- 쓰기는 항상 바꾼 칸만(merge) 합니다. `meta/trip.mapUrl`, `meta/settings`처럼 웹앱에만 있는 값은 건드리지 않습니다.
- 반영한 뒤에는 이 문서의 T0를 그때 반영한 아티팩트의 가장 최근 수정 시각으로 바꿉니다.
